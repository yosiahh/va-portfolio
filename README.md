# Josiah Asa Anota — Virtual Assistant Portfolio

A responsive, single-page portfolio for a General Virtual Assistant with customer service and technical support experience. Built with plain HTML, CSS, and JavaScript for easy GitHub Pages hosting.

## Preview locally
Open `index.html` in your browser. An internet connection is only needed for the optional Google Fonts.

## Publish with GitHub Pages
1. Sign in to GitHub as `yosiahh` (or your actual GitHub account).
2. Create a new public repository named `va-portfolio` (or another name you prefer).
3. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait a few minutes for GitHub Pages to publish the site. The URL should look like `https://yosiahh.github.io/va-portfolio/`.

If you instead use a repository named `yosiahh.github.io`, the site URL is usually `https://yosiahh.github.io/`.

## Before publishing
- Check that the GitHub username and repository name in the URL are correct.
- The site includes your email and phone number because they were included in the supplied resume. Remove the phone line in `index.html` if you prefer not to publish it.
- The three Sample Work cards are explicitly labeled as concepts/demos, not client deliverables.
- Review your public contact details and all wording before making the repository public.
- No build tools or dependencies are required.
